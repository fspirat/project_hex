# Скриншоты для страницы /fstweak/

Положите сюда PNG-файлы с этими именами — страница подхватит их сама
(пока файла нет, вместо него показывается заглушка «Скриншот скоро появится»):

| Файл             | Что на скриншоте                         |
|------------------|------------------------------------------|
| `main.png`       | Главное окно HEX GENERATOR               |
| `palette.png`    | Палитра цветов (клик по полоске цвета)   |
| `presets.png`    | Окно «Пресеты»                           |
| `part-color.png` | Окно «Цвет части»                        |
| `symbols.png`    | Окно «Символы»                           |
| `inventory.png`  | Кнопка ✦ над инвентарём                  |

Лучше всего смотрятся скриншоты 16:9 (например, 1920×1080).
