# fspirat.online

fspirat.online открывается с GitHub Pages (.github/workflows/pages.yml), чтобы сайт был доступен
и там, где блокируют российский хостинг.

Пока здесь нет своих файлов, fspirat.online — зеркало fspirat.ru: публикуется то же, что в sites/fspirat.ru/.
Чтобы сделать fspirat.online отдельным сайтом, положите сюда его файлы — публикация сама переключится на эту папку.
Этот README на сайт не попадает.
