# fspirat.online

Пока здесь нет своих файлов, fspirat.online — зеркало fspirat.ru:
на него выкладывается то же, что лежит в sites/fspirat.ru/.

Чтобы сделать fspirat.online отдельным сайтом, положите сюда его файлы
(index.html и остальное, в том же виде, что на хостинге в /www/fspirat.online) —
выкладка сама переключится на эту папку. Этот README на сервер не загружается.
